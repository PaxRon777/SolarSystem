# Solar System 

Solar System simulator

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![VanillaJS](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)

## 🚀 Tech Stack

- **Frontend**: HTML5, CSS3
- **Logic**: Vanilla JavaScript (ES6+)
- 2K textures are Base64 encoded and the single file can run locally without a web server.

## 🛠 Installation & Usage

Since this is a client-side application, no complex setup is required!

1. Clone or download the repository.
2. Open `solarsystem.html` in any modern web browser (Chrome, Firefox, Edge, Safari).

This project was developed using **vibe coding**—an iterative, high-level conceptual development approach where the developer guides the "vibe" and intent while the AI handles the heavy lifting of implementation.
